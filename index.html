PILOT BRIEFING

把速度交还给天空。

目标：让助推器在平台内，以低速度、接近竖直的姿态着陆。

  1. 先点「开始模拟」火箭从平台上方 95 米开始下降。先熟悉跟随机位，必要时切到远景同时观察平台；随时可以暂停。
  2. 用油门控制下降速度拖动右侧油门，上推增推、下拉减推，松手保持目标油门。电脑也可按住空格增推、松开减推。实际推力有响应延迟，虚线为悬停参考。
  3. 微调姿态，让落点回到平台W / 摇杆上推：远离镜头；S / 下拉：朝向镜头；A、D / 左右：相对当前镜头左右倾斜。你控制的是姿态，推力与惯性决定移动。辅助稳定开启时会帮助回正。
  4. 在接地前完成减速街机模式要求垂直速度 ≤ 3 m/s、倾角 ≤ 10°；真实感模式要求 ≤ 1.8 m/s、≤ 5°。四只脚必须在甲板内，水平速度也须足够低。小雷达的十字中心是平台，亮点是火箭；两者重合代表对准。

手机可同时用左手摇杆、右手油门。自由机位中拖动旋转、双指缩放；打开指南或设置会暂停飞行。
